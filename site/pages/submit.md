# Submit a Resource

We welcome contributions! To suggest a new resource for this collection:

1. **Fork** the [repository on GitHub](https://github.com/CDCgov/influenza-resources).
2. **Create** a Markdown file under `site/_resources/<category>/` following the [content schema](https://github.com/CDCgov/influenza-resources/blob/main/site/_data/schema.md).
3. **Submit** a pull request with your addition.

For detailed contribution guidelines, see [CONTRIBUTING.md](https://github.com/CDCgov/influenza-resources/blob/main/CONTRIBUTING.md).
